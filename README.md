#  カップルデート共有アプリ

カップル向けのデートプラン共有アプリです。ユーザーはデートプランを作成し、共有することができます。


##  主な機能

- デートプランの作成・編集・削除
- パートナーとのプラン共有
- リマインダー通知（予定）
- 思い出の写真アップロード（予定）



## 技術スタック

- フロントエンド: SwiftUI (iOS)
- バックエンド: Laravel 11.x
- データベース: MySQL 8.x
- API通信: REST API (JSON)
- コンテナ環境: Docker / Laravel Sail
