# 要件定義書

## はじめに

Hidamariアプリの投稿・お店管理システムは、ユーザーがお店での体験を写真と共に投稿し、お店情報を管理する機能です。ユーザーは複数の写真とテキストでお店での体験を共有でき、お店情報は管理者が登録・管理します。

## 要件

### 要件1

**ユーザーストーリー:** ユーザーとして、お店での体験を写真と文章で投稿したい。そうすることで他のユーザーと体験を共有できる。

#### 受入基準

1. WHEN ユーザーが投稿作成画面にアクセスする THEN システムは写真選択、テキスト入力、お店選択のフォームを表示する
2. WHEN ユーザーが複数の写真を選択する THEN システムは最大5枚まで写真を受け付ける
3. WHEN ユーザーがテキストを入力する THEN システムは最大500文字まで受け付ける
4. WHEN ユーザーがお店を選択する THEN システムは登録済みのお店一覧から選択できるようにする
5. WHEN ユーザーが投稿ボタンを押す THEN システムは投稿を保存し、お店詳細画面に表示する

### 要件2

**ユーザーストーリー:** ユーザーとして、自分の投稿を編集・削除したい。そうすることで間違いを修正したり、不要な投稿を削除できる。

#### 受入基準

1. WHEN ユーザーが自分の投稿詳細を表示する THEN システムは編集・削除ボタンを表示する
2. WHEN ユーザーが編集ボタンを押す THEN システムは投稿編集画面を表示する
3. WHEN ユーザーが投稿内容を変更して保存する THEN システムは変更を反映する
4. WHEN ユーザーが削除ボタンを押す THEN システムは確認ダイアログを表示する
5. WHEN ユーザーが削除を確認する THEN システムは投稿を削除する



### 要件3

**ユーザーストーリー:** ユーザーとして、お店一覧を見たい。そうすることで興味のあるお店を探せる。

#### 受入基準

1. WHEN ユーザーがお店一覧画面にアクセスする THEN システムは登録済みのお店を一覧表示する
2. WHEN ユーザーがジャンルで絞り込む THEN システムは該当するお店のみを表示する
3. WHEN ユーザーが地図表示を選択する THEN システムはお店を地図上にピンで表示する
4. WHEN ユーザーが現在地検索を使用する THEN システムは現在地から近い順にお店を表示する
5. WHEN ユーザーがお店をタップする THEN システムはお店詳細画面を表示する

### 要件4

**ユーザーストーリー:** ユーザーとして、お店の詳細情報を見たい。そうすることでお店の基本情報とそのお店に関する投稿を確認できる。

#### 受入基準

1. WHEN ユーザーがお店詳細画面にアクセスする THEN システムはお店の基本情報（名前、住所、電話番号、営業時間、ジャンル）を表示する
2. WHEN お店詳細画面を表示する THEN システムはそのお店に関する投稿を新着順で表示する
3. WHEN ユーザーが投稿をタップする THEN システムは投稿詳細画面を表示する
4. IF お店に写真がある THEN システムはお店の写真を表示する

### 要件5

**ユーザーストーリー:** 管理者として、お店情報を登録・編集したい。そうすることでユーザーが投稿時に選択できるお店を管理できる。

#### 受入基準

1. WHEN 管理者がお店管理画面にアクセスする THEN システムは登録済みお店の一覧を表示する
2. WHEN 管理者が新規お店登録ボタンを押す THEN システムはお店情報入力フォームを表示する
3. WHEN 管理者がお店情報を入力して保存する THEN システムはお店を登録し、一覧に追加する
4. WHEN 管理者が既存のお店を編集する THEN システムは編集フォームを表示し、変更を保存する
5. WHEN 管理者がお店を削除する THEN システムは確認後にお店を削除する

### 要件6

**ユーザーストーリー:** ユーザーとして、投稿やお店を検索したい。そうすることで特定の内容を素早く見つけられる。

#### 受入基準

1. WHEN ユーザーが検索画面にアクセスする THEN システムは検索フォームを表示する
2. WHEN ユーザーがキーワードを入力して検索する THEN システムは投稿とお店の両方から該当するものを表示する
3. WHEN 検索結果を表示する THEN システムは投稿とお店を分けて表示する
4. WHEN ユーザーが検索結果をタップする THEN システムは該当する詳細画面を表示する
